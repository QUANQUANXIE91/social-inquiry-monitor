# social-inquiry-monitor（社媒询盘监控）

输入产品关键词，在全球主流社媒/公开网络上自动搜**精准采购询盘**——把"正在找供应商的帖子"从卖家噪音里捞出来，自动查证来源、轻度背调、按可信度分级，输出可直接跟进的询盘清单。

> 咱们这行最贵的不是流量，是**采购信号出现的那一瞬间**。这个技能只干一件事：让你比同行早一步看到它。

## 功能一览

| 能力 | 说明 |
|------|------|
| 🔍 关键词→全球采购询盘 | 产品词 × 四语种采购意图词 × 多渠道搜索式（FB/LinkedIn/Reddit/X/通用搜索） |
| 🧹 采购意图过滤 | 评分制防卖家帖混入，核心判别法：**"我找供应商"=询盘，"我找经销商"=卖家** |
| 🛡️ 自动查证+轻度背调 | 来源查证 + 主体查证（官网存在性/主营/国家），5 分钟/家 |
| 📊 可信度分级 | A（直入 CRM）/ B（入库待补）/ C（只进日报）/ 丢，处置动作明确 |
| 🔗 获客闭环 | A 级直喂 CRM→开发信/跟进流程，是获客流水线的社媒分支 |
| 🎬 二期可选 | cron 定时巡检 / Instagram / 视频剪辑 |

## 触发词

搜采购询盘 / 找求购信息 / 社媒获客巡检 / 采购信号监控 / 关键词找采购商 / social inquiry monitor

## 快速开始

对 Agent 说：

> 用 `<我方产品>` 关键词搜一轮社媒采购询盘，重点看非洲市场

产出：`data/inquiry_<date>.json` + ≤8 行日报，A 级询盘进 CRM。

## 技能定位（组合，不重写）

本技能是**编排层**：抓取用你的社媒抓取/搜索工具，背调用你的快筛技能，入库用你的 CRM 链路。它只负责三件别人都不做的事：**搜索面构建、采购意图过滤、可信度分级**。

## 纪律红线

- 只捞公开信息，不碰私密群、不冒充买家、不绕登录
- **不自动发布任何内容**——发布/私信一律人来发
- 每条询盘带来源 URL + 发帖时间；查证不到标"未确认"，不许脑补
- 排除规则（同行/竞品/已回复客户）由使用方按自己市场配置
